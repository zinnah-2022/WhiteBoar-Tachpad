# লিখন — মোবাইল দিয়ে লেখার হোয়াইটবোর্ড

দুটো অংশ:

| ফোল্ডার | কী | কোথায় চলে |
|---|---|---|
| `desktop/` | **লিখন বোর্ড** — পূর্ণাঙ্গ হোয়াইটবোর্ড সফটওয়্যার | Windows কম্পিউটার |
| `android/` | **লিখন প্যাড** — মোবাইলকে লেখার প্যাড বানায় | Android ফোন |

মোবাইলে যা লিখবেন, কম্পিউটারের বোর্ডে সাথে সাথে (লাইভ) দেখা যাবে। মোবাইলে যত বড় করেই লিখুন, বোর্ডে ঠিক করা সাইজেই বসবে।

## ডাউনলোড ও ইনস্টল

রিপোজিটরির **Releases** অংশে সবসময় সর্বশেষ সংস্করণ থাকে:

- `LikhonBoard-Setup-x.y.z.exe` → কম্পিউটারে চালিয়ে ইনস্টল করুন। ইনস্টলার নিজেই ফায়ারওয়ালে অনুমতি যোগ করে।
- `LikhonPad-x.y.z.apk` → মোবাইলে ডাউনলোড করে খুলুন। “অজানা উৎস থেকে ইনস্টল” অনুমতি চাইলে দিন।

## ব্যবহার

1. কম্পিউটারে **লিখন বোর্ড** খুলুন, উপরে ডানে **মোবাইল সংযোগ** চাপুন।
2. মোবাইল আর কম্পিউটার **একই WiFi**-তে রাখুন (মোবাইলের হটস্পটে কম্পিউটার যুক্ত থাকলেও চলবে)।
3. **লিখন প্যাড** খুলে **QR স্ক্যান** করুন। অ্যাপ না থাকলে ফোনের ক্যামেরা দিয়ে স্ক্যান করলেও ব্রাউজারে প্যাড খুলে যাবে।

### প্যাডের দুই মোড
- **লাইন:** খাতার মতো একটা পট্টিতে লিখুন। বোর্ডে লেখা নির্দিষ্ট উচ্চতায় বসে (বোর্ডের সংযোগ প্যানেলে সাইজ বদলানো যায়)। **পরের শব্দ** চাপলে ফাঁকা জায়গা আসে, **নতুন লাইন** চাপলে বোর্ডে পরের লাইনে যায়। বোর্ডের 📱 টুল দিয়ে ঠিক করুন লেখা কোথা থেকে শুরু হবে।
- **ফ্রি:** পুরো বোর্ড মোবাইলের পর্দায় — যেখানে খুশি লিখুন, আঁকুন, লেজার পয়েন্টার ব্যবহার করুন।

### বোর্ডের সুবিধা
কলম (চাপ-সংবেদী স্টাইলাস সমর্থন), হাইলাইটার, ইরেজার, রেখা, তীর, আয়ত, বৃত্ত, ত্রিভুজ (ভরাট/ড্যাশ), বাংলা টেক্সট, ছবি (ফাইল, কপি-পেস্ট, টেনে আনা), লেজার পয়েন্টার, নির্বাচন-সরানো-ডুপ্লিকেট-মুছা, Undo/Redo, অসীম ক্যানভাস, জুম, একাধিক পেজ, ৬ রকম বোর্ড রং (সবুজ/কালো বোর্ডসহ), গ্রিড/ডট/রুল নকশা, `.likhon` ফাইলে সেভ-খোলা, স্বয়ংক্রিয় সেভ, PNG ও PDF রপ্তানি, ফুলস্ক্রিন, কিবোর্ড শর্টকাট (`?` চাপুন)।

## নতুন সংস্করণ বানানো

`main` শাখায় কিছু পুশ করলেই GitHub Actions নিজে থেকে `.exe` আর `.apk` বানিয়ে নতুন Release প্রকাশ করে (১০–১৫ মিনিট)।

নিজের কম্পিউটারে চালাতে চাইলে:

```bash
cd desktop
npm install
npm start          # বোর্ড চালু
npm run dist       # Windows ইনস্টলার তৈরি (dist/ ফোল্ডারে)
```

Android অ্যাপ Android Studio দিয়ে `android/` ফোল্ডার খুলে চালানো যায়।

## কারিগরি তথ্য
- বোর্ড: Electron, Canvas 2D; কালির রেখা [perfect-freehand](https://github.com/steveruizok/perfect-freehand) (MIT), QR কোড [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT)।
- সংযোগ: বোর্ড পোর্ট `8765`-এ একটা ছোট সার্ভার চালায়; প্যাড WebSocket দিয়ে কলমের প্রতিটি বিন্দু পাঠায়। ৪ অঙ্কের পিন ছাড়া কেউ যুক্ত হতে পারে না।
- প্যাড অ্যাপ: Kotlin + WebView; লেখার পর্দা কম্পিউটার থেকেই আসে, তাই বোর্ড আপডেট করলে প্যাডও আপডেট হয়।
- `android/app/likhon.keystore` দিয়ে অ্যাপ সাইন হয়, যাতে নতুন সংস্করণ পুরোনোটার ওপর ইনস্টল হয়। Play Store-এ দিতে চাইলে নতুন গোপন কী বানিয়ে GitHub Secrets-এ রাখুন।
